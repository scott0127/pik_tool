# 手機版修正：2026-10-02

## 動畫腳本

- 導覽：點選選單後，在固定高度的 Header 下方顯示不透明面板，由上方 8px 歸位；底下頁面與地圖不位移。收起反向退出。Vue Transition 處理連續反向操作，減少動態時直接切換；切頁與卸載解除捲動鎖。
- 好友：手機卡片進入視窗時由下方 12px 歸位一次，之後保持端正，不再跟隨閱讀進度傾斜、縮小或退出。桌面保留紙張透視；跨斷點重建並清除前一套動畫，卸載清理。
- 地圖：容器從隱藏變可見、旋轉或高度改變時，下一個畫面更新 Leaflet 尺寸，不播放位移動畫；離頁停止觀察及未執行的更新。

## 修正範圍

- 圖鑑封面提供 20px 內距（最窄尺寸 16px），插圖另留右側安全距離；取消頁面負邊距。
- 手機導覽改為覆蓋面板，使用穩定不透明底色，避免開合切換 backdrop-filter 與擠壓頁面。
- Leaflet 改為觀察實際容器尺寸，取代只執行一次、可能早於 Leaflet ready 的可見性輪詢。
- 好友手機目錄取消透視與旋轉，縮小卡片間距，序號移入卡片內。
