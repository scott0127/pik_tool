# 首頁收藏圓環：輕量凸透鏡

目前依使用者的新參考圖，恢復同心圓、白色中央圓、線條小芽、粗體百分比與薄荷色收藏徽章。只改外圈的凸透鏡質感，首頁構圖維持原樣。

目前實作用單一平面與程序 shader 解析凸面法線、折光環境、同心圓和進度。每次繪製只有一個 draw call，不再使用離屏 render target 或背面法線貼圖；沒有常駐 RAF，靜置不重繪。DPR 上限 1.5、繪圖邊長上限 576px。背景是假折射環境，沒有擷取或扭曲網頁 DOM。

早期原型曾參考 Jesper Vos / Codrops 的 [Real-time Multiside Refraction in Three Steps](https://tympanus.net/codrops/2019/10/29/real-time-multiside-refraction-in-three-steps/)。以下保留設計歷程；最後一節為目前版本。

## 動畫腳本

- 起始：沿用首頁圓環、綠色進度、白色數字核心與收藏徽章。背景光斑渲染在同一場景，透明圓面與環軌折射這些背景。
- 觸發：點圓環或底下的浮起／放回按鈕，鍵盤 Enter／Space 同樣可用。
- 順序：玻璃抬升並輕微傾斜 → 正反面法線改變背景取樣 → 數字核心前移、投影展開。數字保持正面可讀。
- 收回：從目前姿態平順落回，不額外旋轉或換形。
- 中斷：快速點擊覆寫既有動畫；手機直向手勢交由頁面，不使用裝置方向權限。
- 減少動態：停止背景流動，狀態立即完成。離開視窗或背景分頁停止繪製，卸載釋放 render targets、材質、幾何與事件。

## 驗收

檢查玻璃是否確實改變後方光斑位置、環軌是否有厚度和明暗、中央百分比是否穩定可讀，以及手機是否溢出／搶走滑動手勢。瀏覽器手機尺寸測試不代表 Samsung／iPhone 實機 GPU 效能。

### 2026-10-02 驗證結果

- Codex 的 Chrome 瀏覽器，320×740、393×852、1280×900：圓環在容器內，頁面沒有水平溢出。窄版數字仍保有清楚留白。
- 比較靜止與浮起的連續狀態：圓面輪廓、環軌、光斑扭曲位置都有改變；中央文字保持正面，避免因旋轉而難讀。進度弧直接附著在同一個 3D 物件上。
- 六次快速反覆點擊能接續目前姿態；減少動態設定可立即切換狀態。Canvas 只在可見且分頁前景時持續繪製。
- 正式打包成功；3003 正式預覽的首頁可操作，瀏覽器沒有 error / warn。
- 型別檢查沒有這次新增檔案的錯誤；專案仍有 13 個既存型別錯誤（Admin、FooterFlipCounter、HeroSection 分類解析與 friends）。
- 這是圓環形式的教學算法應用，不是鑽石場景的逐像素復刻；取樣背景是 Canvas 內的柔光背景，無法折射網頁文字或 Canvas 外物件。尚未測量真實手機 GPU 效能。

## 2026-10-08 植物玻璃標本微調

保留首頁構圖與原有圓環操作，將圓環修成薄荷色光學玻璃標本。收斂大片黃粉光斑，加入窄窗光、薄切邊、細刻度和植物露珠；中央使用較輕的襯線數字，收藏數量改為透明刻字標籤。

### 動畫腳本

- 起始：玻璃平放，植物葉片收攏，刻度對應收藏進度；文字保持正面。
- 觸發：點擊圓環或提示按鈕，亦支援 Enter／Space。
- 順序：0–0.8 秒玻璃抬升、微傾與陰影展開，同時小芽展葉；一道窄光在 0.95 秒內掃過表面後消失。
- 結果：停在浮起姿態，提示改為「輕點放回」。不增加常駐閃光或粒子迴圈。
- 收回與中斷：再次點擊從目前姿態平順放回；連續操作先終止前一條時間軸，保持狀態同步。
- 減少動態：立即切換姿態，取消掃光、葉片與陰影過渡；沿用離屏／背景分頁停止 WebGL 繪製和卸載清理。

### 驗證

- Codex Chrome：320×740、390×844 無水平溢出；確認小螢幕數字與按鈕仍在容器內。
- 浮起／放回、六次連續點擊、鍵盤 Enter 正常；減少動態下掃光透明度為 0，陰影過渡時間為 0。
- 玻璃材質沿用既有渲染流程，沒有增加網格、貼圖或 render pass；移除 GSAP 更新時的重複繪製，交由可見時的既有繪製迴圈處理。
- Vue 元件編譯與正式打包通過。此驗證未包含真實手機 GPU 測量。

## 2026-10-08 高冰翡翠修訂

以[高冰晴水平安扣的材質照片](https://www.jaadee.com/Jade/316971.html)作為質感參考，改成淡青綠冰透玉盤。透光與含蓄的內部色澤來自程序材質；不使用圖片背景，也不新增貼圖或渲染步驟。這是視覺模擬，沒有實作完整體積光追。

### 動畫腳本

- 靜置：圓潤玉盤厚邊蓄色、中心清透，保留細綠色進度軌。中央百分比直接呈現在玉面，移除白色圓底、英文裝飾與刻度。
- 觸發：點玉環或「輕觸，浮起玉環」，鍵盤 Enter／Space 亦可操作。
- 順序：0.95 秒抬升與微傾，拋光反射跟隨曲面角度變化，文字輕微前移、投影展開。移除額外橫掃白光及植物展葉，讓玉質本身表達角度變化。
- 結果：提示切為「輕點放回」，百分比保持正面可讀。
- 收回與中斷：重新點擊從目前姿態反向；先終止前一次 GSAP tween，避免反覆操作排隊。
- 減少動態與清理：即時完成姿態、取消 CSS 過渡，沿用離屏／背景停止繪製與卸載釋放資源。

### 此次驗證

- Chrome 320px：沒有水平溢出，百分比字級 38px，提示按鈕保留 44px 觸控高度；Enter 與連續六次點擊後狀態一致。
- 減少動態設定下，文字層與投影過渡均為 0 秒；抬升／放回仍可操作。
- 材質增加拋光高光、深青厚邊及窄內部回光；圓環外保留透明，減少一次最後輸出的背景繪製。
- Vue 元件編譯、材質單檔 TypeScript 與正式打包通過；瀏覽器沒有 error／warn。未測量真實手機 GPU 效能。

## 2026-10-08 原造型與手機效能修訂

### 動畫腳本

- 起始：保留參考圖的三層圓環、白色圓心、小芽、粗體數字與圓角收藏徽章。外圈為透明凸透鏡，帶薄荷、淡暖色折光與細弧面高光。
- 觸發：點圓環或提示，亦支援 Enter／Space。
- 動作：0.95 秒輕微抬升、傾斜，高光隨凸面法線改變；數字圓心與徽章輕微前移，保持正面可讀。
- 結果：停在選定姿態且不再重繪；再點從目前姿態平順放回。
- 中斷：先停止舊 tween，從當下角度反向；減少動態即刻完成，離屏／背景分頁不繪製，回來時補繪最新姿態。

### 效能策略

- 一個平面、一個 shader、一個 draw call；無紋理、FBO、後處理或持續時間變數。
- GSAP onUpdate 才要求新畫面，未改變的 pose 會略過。收藏進度與尺寸改變也會更新。
- Canvas 在靠近視窗時才載入；繪圖像素上限 576×576，文字仍使用 DOM 保持清晰。
- 不新增常駐計時器或動態模糊；影子使用靜態徑向漸層搭配 transform／opacity。

### 瀏覽器量測

- Chrome 暫時攔截此 canvas 的 WebGL draw 呼叫：靜置 2,004ms 為 0 次；完成點擊動畫後再次觀察 1,500ms，亦為 0 次。量測程式已移除，不包含在產品程式碼。
- 桌面 384px 元件的實際 drawing buffer 為 576×576，符合解析度上限。
- 320px 手機尺寸無水平溢出，保留 44px 提示按鈕；連續六次點擊狀態一致。動畫中切換減少動態後文字和陰影皆為零過渡，離開首頁再返回可重新顯示透鏡。
- Vue 元件編譯、材質單檔 strict TypeScript 與正式打包通過，返回首頁後瀏覽器沒有 error／warn。
- 以上為桌面 Chromium 量測；未聲稱已測量真實手機 GPU 幀率。首頁其他背景動畫仍獨立運行。
