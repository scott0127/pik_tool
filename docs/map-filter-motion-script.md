# 飾品地點篩選：探索手冊動態腳本

## 視覺語言

地圖上的底部篩選列就是收起的手冊；點開後延展為閱讀與選取的面板。主題綠與白字維持一致，灰綠紙張邊線作點綴。動作服務狀態與因果，每段有開始、閱讀停留、收回。

| 段落 | 觸發 / 時間 | 畫面與動作 | 結果 |
| --- | --- | --- | --- |
| 打開封面 | 點篩選列，0–460ms | 面板從篩選列實際位置與大小延展；綠色書脊隨後展開 | 同一個入口變成手冊 |
| 翻到內容 | 220–560ms | 標題微微翻正，統計與提示依序露出 | 先建立面板用途和目前狀態 |
| 攤開選項 | 340–約650ms | 手機左右兩列卡片交錯移入、微角度回正；只動畫可見卡片 | 名稱安定可讀，能直接滑動清單 |
| 操作落點 | 勾選或取消 | 勾選章落下、數量更新；行囊打開時指南針回應 | 使用者看見選擇造成的結果 |
| 收攏內容 | 完成、關閉、Esc 或下拉，0–約220ms | 可見卡片從末端收攏，標題與統計退場 | 內容先收好 |
| 回到入口 | 120–460ms | 面板回到篩選列位置與大小，交還地圖視野 | 篩選數量保留於底部入口 |

## 實作限制

- 使用目前面板與卡片，無新增動畫套件或循環裝飾。
- GSAP context 限定在此組件；取消與卸載停止時間軸並清除樣式。
- 減少動態效果時直接切換；鍵盤開啟後焦點進入關閉按鈕，收起後適當還原入口焦點。
- 手機下拉未達關閉距離會回彈；行囊互動不觸發面板拖曳。
- 未來介面同樣先規劃觸發、物件狀態、轉場銜接與中斷，再做動畫；不將所有組件套同一種淡入滑動。
