# Project Notes

This folder keeps non-runtime project notes and archived review artifacts out of the app root.

- `design/`: visual direction, GSAP motion notes, and design principles.
- `engineering/`: implementation architecture, data pipelines, and correctness invariants.
- `operations/`: deployment, production operations, and incident runbooks.
- `archive/`: old verification output and historical notes that are useful for reference but not part of the app runtime.
