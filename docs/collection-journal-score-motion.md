# 收藏誌與積分紀錄頁

手機優先；角色使用現有單張平面 PNG，圖片 contain 保留比例，不生成新姿勢。每組七／八色按三欄換列，自然留白；360px 以下採兩欄保留閱讀空間，多組按原始飾品分段。

## 動畫腳本

- 封面：進入畫面，三張紙卡輕微錯開；點封面紙卡，卡片分開再落回，銜接翻到圖鑑。減少動態時直接翻到正文。
- 分類：點頁籤／分類列，紙面展開，標本按列進入；收合沿原路返回。反覆操作從目前狀態轉向；保留原生捲動。
- 積分頁：點「積分紀錄」，摘要下的紀錄紙面展開，進度與顏色選單先出現，再露出操作列。收合回摘要；中斷清理動畫，不留下固定高度。
- 換顏色：點四色兩列的顏色頁籤，選取狀態立即改變，平面圖片與操作列小幅入場；每次只顯示一色的五種狀態，避免八份長表。
- 調數量：加減按鈕按壓，真實數量與點數立即更新；數字輕移回正，真實積分差額短暫顯示，進度條跟上。小盆栽庫存不產生虛構積分。快速點擊仍依序更新資料；新回饋取代舊回饋。
- 計分規則／近期紀錄：在同一張紙內揭開補充資訊，保留既有計分值與事件來源。

減少動態偏好直接顯示結果，卸載停止 GSAP 與監聽，鍵盤焦點可見，加減和顏色選取觸控區至少 44px。
