# 頁尾翻牌：動畫腳本

- 參考：[PQINA Flip](https://pqina.nl/flip/) 的上下半牌、翻動時加深的投影，以及 [Tick Flip](https://pqina.nl/tick/) 對落定速度與板面深度的處理。用既有 GSAP 實作，保留本站主題綠。
- 觸發：翻牌計數器進入可讀範圍時開始持續循環；不依賴 hover。資料尚未取得時顯示短橫，讀取後使用既有真實瀏覽次數。標題只寫「總瀏覽次數」。
- 起始狀態：主題綠的獨立數字牌、白色等寬數字、上下半牌與中央接縫；奶油色承座和輕微底部厚度。完整計數供讀屏使用，裝飾半牌不重複朗讀。
- 順序：上半牌沿中央軸向前翻下，中縫投影加深；下半牌接續落定並輕微回彈。各數位短暫錯開，整段約一秒；停留約一點五秒後開始下一輪。逗號保持穩定，資訊連結與觸控區不跟著移動。
- 結果：循環翻動同一組實際數值，沒有虛構計數。之後真實數值更新只翻變動的數位，再恢復循環。
- 收回／中斷：滑出畫面或頁籤隱藏立即停止並落定；返回後恢復。快速更新先停止前段動作，再以最新數值接續；減少動態偏好中途切換時立即落定；卸載移除 observer、timeline 與 listener。
- 頁尾佈局：手機先呈現計數承座，接著資料來源、支援與聯絡；桌面並排。完整授權文字保留在可展開的原生 disclosure，操作有明確開合狀態。
