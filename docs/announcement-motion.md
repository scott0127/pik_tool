# 公告動畫：情報卡展冊

依使用者確認的腳本，以 GSAP Timeline 與公告內分層視差實作。手機優先，從一疊卡片抽開成四列，再安靜閱讀。

## 動畫腳本

- 觸發：網站載入遮罩完成退場後，首次顯示公告，確保開場動畫能完整看見。
- 0–280ms：四張卡片重疊在內容區中間，以 4px 水平／5px 垂直階差、少量傾斜與縮放形成卡疊。前方保留 9/30 標籤，整疊向上抬起 26px。
- 100–440ms：後方玻璃底板以 16px 位移跟上；頁籤、關閉鈕及進度軌道逐漸出現。
- 160–875ms：四張卡依閱讀順序抽開，每張相隔 85ms，以 460ms 的平滑加減速移至實際列位置並扶正。
- 370–950ms：日期標籤落定，文字清楚呈現，小圖示稍晚輕彈落定。
- 150–800ms：後景光影以 6px 位移慢速歸位；700–950ms 玻璃邊緣掠過一次反光。
- 結果：950ms 後完全靜止並開始 10 秒閱讀倒數；3 秒後自動切換活動頁。手動選頁會取消自動切頁。
- 切頁：綠色選取底片即時滑向新頁籤；舊頁 160ms 退出、新頁 320ms 抽入，前景卡片多移動 8px、後景光影反向移動 6px。切頁只平移、不縮放文字。兩頁以共用格位預留高度，外框保持穩定。
- 操作回饋：複製成功後按鈕變綠、顯示「已複製！」與勾選，保留 2 秒。
- 收回：下方卡片先收攏，再依序疊回；玻璃底板稍晚跟著下沉，總長 400ms。
- 中斷：快速切頁從當下位置接往最後選擇；開場途中可切頁或收回。關閉時停止計時，卸載清理所有 GSAP 動畫及監聽。
- 減少動態：直接顯示／切換／關閉，保留狀態與功能性倒數；系統偏好改變時也會完成當前動畫。

## 圖層與驗收

後景光影、中景玻璃、前景卡片各自獨立，視差僅在操作時播放；玻璃不彈跳。固定外框與頁面高度，使用 transform / opacity 呈現移動與倒數，避免動畫造成捲軸推擠。

只保留底板一層背景模糊，內部控制元件不重複取樣背景。GSAP 控制的移動不疊加 CSS transition；卡片僅在展開時使用 will-change，完成或切頁中斷後移除，避免閒置時保留額外圖層。

驗收需看正常速度下的疊卡、半展開、完整四列三個畫面，並檢查 320px / 390px / 桌面、快速切頁、開場中關閉、複製與減少動態偏好。
