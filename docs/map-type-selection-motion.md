# 地圖類型選取：袖珍紙片舞台

## 動畫腳本

### 按鈕本體（補充）

- 點擊立即切換勾選；原位的編號讓出一個飾品位置，按鈕內的纸道具、文字面與飾品分開動，不需看向統計區才知道操作結果。
- 咖啡的杯碟與三道蒸氣、車站的車票與打孔、郵局的信封折片、電影的拍板、圖書的書頁、戶外的葉片／水紋均直接出現在按鈕上。其餘種類沿用相應動作語意並使用自己的飾品圖片。
- 選取是展開、進場、落章；取消是抽出、收攏、退場。文字在短暫移位後回到閱讀位置；約 1.1 秒完成，不持續循環、不改變列高、不阻塞後續點擊。
- 再次點擊停止上一段、從確定的起始姿態播最新狀態；轉點其他種類立即清理舊按鈕。全選、清除、關閉與卸載均清理；減少動態時只保留正常選取切換。

- 觸發：類型的原生勾選框變更，立即更新篩選與數量。舞台放在統計右側，不把手機清單撐開，不遮住類型名稱。
- 起始：第一次操作時紙舞台展開；後續更換種類停止並清理前一組物件，再換入下一組。手機面板微微提高以保留清單空間。使用圖鑑裡該種類的兩張獨立平面圖片，搭配可分開動的紙道具與前景。
- 選取：依種類編排物件操作，角色落到閱讀位置，勾選章落下。例如咖啡杯落到杯碟後蒸氣升起、火車依序進站與車票打孔、郵票角色滑進信封、電影拍板打開後合上。
- 結果：角色與物件安定，顯示該種類已納入篩選；文字與篩選控制一直可以操作，沒有持續晃動。
- 取消：短暫展示該種類，再依動作方向收回角色與道具，留下收起的舞台及移出篩選狀態。
- 中斷：再次操作直接停止並清理前一段時間軸，以最新勾選狀態編排。全選／清除收回單一種類舞台；關閉面板卸載舞台。圖片載入成功才開始該段；失敗以既有本地皮克敏代替，不阻塞選取。
- 減少動態：保留種類圖片與結果，直接切换；偏好即時變更時終止時間軸。所有動畫使用局部 GSAP context，卸載清理。

## 種類分鏡

| 種類 | 道具與動作 |
| --- | --- |
| 餐廳、壽司 | 餐盤攤開，角色依序上菜；壽司由側面滑入 |
| 咖啡、拉麵、咖哩、韓式 | 杯碟／碗盤先落位，角色落下，再升起三道蒸氣 |
| 甜點、麵包、漢堡、義式、墨西哥 | 烘焙托盤、包裝紙或餐盒展開，兩份食物分次落位 |
| 便利商店、超市、服飾、飯店 | 紙袋／備品盒打開，兩件物品依序裝入 |
| 化妝品、藥局、電器、五金、美髮 | 鏡盒開蓋、藥盒取物、電池充電、工具扣緊、剪刀交錯剪切 |
| 圖書、文具、大學、神社、路邊 | 書頁攤開、筆畫拉出、徽章落下、籤紙抽出、貼紙貼上 |
| 郵局 | 信封打開，郵票角色進入，封口合回 |
| 車站、公車、機場、橋 | 車票／道路展開，角色依序進站、起飛、跨越 |
| 公園、森林、動物園、山丘 | 紙葉前後展開、飾品角色穿出；山形背景分層立起 |
| 水邊、海邊 | 角色掠過水面，兩層水紋分次展開 |
| 遊樂園、體育館、美術館、電影 | 門票旋入、球彈落、畫框展開、拍板開合 |
| 雨天、下雪 | 雲片滑入後落雨／雪，葉帽／雪飾品角色就位 |

圖片沿用圖鑑來源，以實際圖片名稱對應規則 ID（包含不同的連字號、便利商店、服飾店與文具 ID），不使用 emoji 當場景素材。
