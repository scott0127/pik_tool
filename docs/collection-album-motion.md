# 圖鑑收藏冊：動畫腳本

方向：沿用好友頁的奶油紙張、主題綠與分層插畫，借鏡 Ponpon Mania 的物件前後景、Digital Stamp Collection 的紙張整理方式。原有搜尋、收藏、稀有分析與庫存功能保留；手機先看到封面、搜尋和第一組飾品。

| 觸發 | 起始與動作順序 | 結果／收回／中斷 |
| --- | --- | --- |
| 捲過封面 | 風景明信片、三張標本與書脊分層；背景緩移，標本微微展開 | 原生捲動，返回時按原路回復；不占額外捲動高度 |
| 開啟篩選 | 背景變暗，紙頁從底部抽出，頁籤和篩選組依序定位 | 選取使用主題綠白字；關閉紙頁收回，焦點回到入口；快速重點終止上一段 |
| 展開分類 | 索引標籤打開，冊頁增高，內容向下展平 | 名稱和進度保持穩定；收起時內容收回；折疊內容不可取得鍵盤焦點 |
| 搜尋／選取篩選 | 結果紙頁短暫後移，再向前定位 | 更新的是同一收藏冊；不逐張重播所有飾品 |
| 收藏標本 | 圖片壓入口袋，綠色收藏章落下 | 取消時先揭章；連續點擊依最新真實收藏狀態收斂 |
| 稀有分析 | 點分析頁籤，內容展開 | 預設收起，避免手機主內容被分析佔滿；隨時可收回 |

所有動畫在減少動態偏好開啟時立即停止並保持操作結果。卸載清除自身 GSAP、觀察器、鍵盤事件與頁面鎖定。文字、搜尋與收藏不依賴 hover。

## 實際驗證

- Codex 內建 Chromium 瀏覽器：320px、393px 與 1280px；手機沒有橫向溢出，桌面目錄不遮擋篩選按鈕。
- 紅皮克敏 + 特殊飾品得到 76 個結果；單卡系列密排，320px 兩欄、393px 三欄。
- 收藏、快速取消／再次收藏後還原；總收藏數回到測試前的 0。
- 篩選抽頁、快速開關、開啟期間切換減少動態、關閉焦點恢復與跨 768px 的捲動鎖定。
- 分類收合與 inert、目錄特殊章節切換、指定香腸分類跳轉、背景捲動恢復。
- Vue 元件編譯與 Nuxt 正式建置通過。未使用實體 iPhone 或 Samsung 裝置測試。

參考：[Ponpon Mania](https://ponpon-mania.com/) 的圖層編排與 [Digital Stamp Collection](https://marijanapav.com/stamps) 的收藏材質。使用專案既有插畫與皮克敏素材，來源見 `friends-comic-art.md`。
