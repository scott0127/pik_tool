# Collection 動畫規範

整頁採用「短促回應、柔和收尾」：一般操作不等待動畫，較明顯的彈性只用於收集成功。手機與桌機沿用相同節奏，不改既有版面斷點。

共用參數位於 `app/utils/collectionMotion.ts`，不要為每個元件另造一組時間。

| 用途 | 時間 | 動作 |
| --- | --- | --- |
| 按下／角色起跳 | 120ms | 卡片微縮、角色上移 6px |
| 離開／取消 | 180ms | 輕淡出或回復原位 |
| 面板、選項、結果切換 | 280ms | `power2.out`，位移 6–8px；選項輕微回彈 |
| 進場、收集回彈 | 360ms | 進場柔和收尾；收集使用 `back.out(1.25)` |

## 各區行為

- 頁首與搜尋面板：一次輕移入場，不在每次資料更新時重播。
- 篩選選項：狀態立即更新，按下的那顆按鈕回彈；不影響輸入焦點。
- 結果切換：只動畫化一個結果容器，不建立每張卡片的進場 timeline。
- 手機篩選：遮罩原地淡入，面板從下方 32px 滑入；兩者分開動畫，避免遮罩跟著整頁移動。
- 分類展開：只有視窗內分類動畫化高度及內容；批次操作沿用分批更新，畫面外不做高度動畫。
- 收藏卡片：一般收集為角色小跳、勾勾落下，約 400ms；稀有收集加一道掃光，約 480ms。取消收集回復原位。連續操作先收尾上一段，不累積特效。
- 進度條：透過 `scaleX` 更新，綠色／紫色／金色沿用現有分類與完成語意。

## 效能與無障礙

- 卡片只在靠近視窗時由既有 IntersectionObserver 建立，禁止每個分類掛載時都預建數排卡片。
- 不常駐粒子、閃爍、卡片多層背景模糊，也不逐幀動畫化圖片濾鏡。
- 按鈕的顏色過渡使用 CSS；GSAP 管理需要先後順序、取消與清理的互動。
- GSAP 選取範圍限於頁面或卡片自身；切頁清理 context，卡片卸載取消 timeline 及待完成回饋。
- 支援 `prefers-reduced-motion`，功能直接更新、跳過互動動畫。
- 收藏卡片支援 Enter、Space、`aria-pressed` 及可見焦點框。

## 驗證方式

用桌機與手機尺寸驗證篩選進出、快速連續收藏／取消、分類展開、切頁和減少動態效果。動畫完成後不得殘留透明度或 transform，不得讓手機水平溢出。

效能記錄應區分正常速率與 CPU 降速，不將開發機的單次幀率視為實體低階手機保證。
