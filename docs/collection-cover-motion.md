# 圖鑑封面動畫腳本

- **物件與起始狀態**：奶油色收藏手帖、主題綠書脊、背景風景明信片，以及紅、黃、藍三張獨立標本卡。標題、收藏數與閱讀按鈕一直保持清楚。
- **捲動觸發**：原生捲動離開封面時，風景往後退 12px，標本卡往上移 10px 並稍微攤開，形成翻進收藏內頁的層次；往回捲時沿原路收回。沒有釘住畫面或額外捲動距離。
- **觸控／鍵盤觸發**：按「翻開圖鑑」或點標本卡，立即通知頁面前往收藏內頁。三張卡依序抽出、展開，再回到原位，作為翻開動作的回應。
- **快速操作與中斷**：每次只播放一段回應，不累積動畫；動畫中反覆按不重複通知。減少動態偏好啟用時立即停止並還原，按鈕直接執行。卸載時清理時間軸、ScrollTrigger 與媒體監聽。
- **手機版**：封面保持約 260px 高，標本卡只佔右側，不遮住標題、進度與按鈕；兩個開啟入口皆保留至少 44px 觸控區。
