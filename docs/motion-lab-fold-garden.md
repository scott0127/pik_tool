# 紙本收藏／種一朵花：動畫腳本

此為獨立 motion-lab 範本，不改正式地圖。

## 書店

- 觸發：點選奶油色的「書店」卡片；文字與篩選結果立刻更新。
- 起始：右上邊框停著合起的小書，書頁與書籤藏在封面內。
- 動作：卡片輕壓回彈 → 封面沿書脊打開 → 三層紙頁依序攤開 → 書籤滑出。
- 結果：翻開的書停在邊框上，卡片使用主題綠與白字，文字保持固定位置。
- 取消：從目前進度反播，先收書籤、再疊回紙頁、最後合起封面。

## 花店

- 觸發：點選奶油色的「花店」卡片；選取狀態立即更新。
- 起始：邊框上只有小陶盆與土壤，種子／莖／葉／花都收好。
- 動作：卡片輕壓回彈 → 種子落入土中 → 莖長出 → 兩片葉子展開 → 花瓣依序綻放。
- 結果：花停在邊框上，盆與花為分層 CSS 物件，沒有整張圖片抖動。
- 取消：花瓣收攏、葉片收回、莖縮回土中，保留初始陶盆。

## 共同行為

- 快速反覆點擊直接改變同一 timeline 的播放方向，不重建或排隊。
- speed 改變 timeline 的 timeScale；文字不追隨動畫移位。
- prefers-reduced-motion 或 reducedMotion=true 直接套用終點／起點。
- reset() 回到未選取狀態；卸載回收 context、按壓動畫與偏好監聽。
