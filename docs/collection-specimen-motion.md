# 圖鑑標本卡動畫腳本

- **觸發**：點標本卡、按 Enter 或空白鍵，立即切換既有收藏資料，並保留原有提示和 toggle 事件。
- **起始**：未收藏仍清楚呈現皮克敏與識別色；奶油紙卡、裱紙、標本、透明口袋、收藏章為獨立層。文字始終留在紙卡下方。
- **收藏順序**：紙卡輕壓 → 標本下移 5px、收進口袋 → 口袋邊緣回到定位 → 綠底白字收藏章從上方落下並微轉 -3°。總長約 0.48 秒。
- **取消順序**：收藏章往上揭起淡出 → 露出「點一下收藏」 → 標本回到展示位置。
- **結果**：綠章只表示真實收藏狀態；稀有僅用低飽和金色標籤點綴，物種顏色仍保留。
- **中斷**：重複點擊先還原上一段動畫，使用最新資料重播；開啟減少動態立即中斷並顯示最終狀態；卸載還原所有動畫並移除監聽。
- **版面**：手機三欄；名稱最多兩行，翻譯一行，收藏標籤不遮住圖像。保留分組可見性掛載及預載；估算高度加上名稱與收藏章區域，使用圖鑑容器實際寬度。
