# 探險工具：收合入口與共用教學

依使用者確認的腳本實作，延續奶白紙卡、Header 主題綠 #10B981 與分層 GSAP 動畫。重點在未展開時辨識用途，並以獨立「？玩法」入口統一教學，不讓教學按鈕順便展開主功能。

## 動畫腳本

- 觸發：工具入口首次進入畫面且維持收合。標題、數字、操作始終清楚可讀。
- 保底進度：金色花苗袋前方的小卡抽出，三條比較刻度依序推進，金色目標點亮起，袋面掠過一道柔光；約 0.9 秒後停住。刻度屬裝飾示意，不呈現假數值。
- 手帳：封面微開、內頁抽出、記錄標記落入、書籤露出；約 0.9 秒後停住。
- 粒子：收合時的主操作採綠色膠囊，薄光沿邊緣流過，少量白色光點與光帶匯向右側白色圓鈕。裝飾集中於文字下方，約 1.2 秒後靜止；旁邊獨立問號書籤開啟教學。
- 提醒：未操作時隔 6 秒再播放一次，之後不循環；離屏與瀏覽器背景暫停，展開後清理。
- 教學：點問號，書籤壓下、背後紙層露出，手機底部／桌面中央教學卡展開。底板、圖示、文字分層進入，閱讀內容固定高度。
- 教學切頁：舊卡收出，新卡以不同層次的位移接入；手動下一步，不自動切換。示意均標示「範例」，不修改實際庫存或積分。
- 收回：教學卡疊回、面板收下、焦點回到問號。最後一步主操作關閉教學並展開對應功能。
- 中斷：快速反覆點擊以最後操作為準；關閉可中斷進場。減少動態偏好即時生效，卸載移除動畫、觀察器與監聽。

## 功能文案與驗收

「金盆栽保底進度」採金色花苗袋與進度卡視覺，用途是快速比較所有種類中哪些最接近保底金盆栽。教學區分目前積分、待培養庫存與缺色；入口摘要只採用真實紀錄。積分手帳說明按系列與顏色記下拔苗、拿裝飾與放生，再追蹤庫存及稀有進度。

以 Codex Chrome 瀏覽器驗證 320px、390px、桌面；檢查收合入口、教學三步、關閉／Escape／焦點回復、快速切頁、開始操作、減少動態與橫向溢出。避免新增外部素材、Canvas、常駐模糊與永續粒子循環。
