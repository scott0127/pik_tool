# 首頁流光點綴

沿用原先首頁標題、文案、活動展示、缺少清單與收藏圓環的尺寸、順序和位置。主頁只增加細節，不新增首屏區塊。

## 動畫腳本

- 背景：奶油白與淡綠作底，三道薄荷光帶緩慢交疊，表達柔和緞面的流動反光。以 CSS 漸層建立多層光帶，GSAP 只改 transform 與 opacity；不使用圖片、影片或新 WebGL 場景。
- 觸發：進入首頁，背景以不同相位開始緩慢流動；每次往返約 16–23 秒，沒有開場閃白。
- 點綴：保留 GARDEN TRACKER 原徽章，綠色小點多兩片小葉，隨原本進場動畫短暫展開一次。
- 結果：文字與工具排列不變，背景持續低幅度流動，前景小葉完成後靜止。
- 中斷：分頁隱藏暫停背景，回到前景接續；離開首頁卸載並清理。手機降低移動幅度。
- 減少動態：背景維持完整靜態配色，小葉直接呈現完成樣子。

## 2026-10-08 驗證

- Codex Chrome 預覽確認原版標題、文字與工具排列；手機和桌面無水平溢出。
- 背景各層的 transform 隨時間改變；切換減少動態後回到 CSS 靜態姿態，連續兩次觀察維持相同。
- 所有背景層皆為 CSS 漸層，沒有圖片 URL；Vue 編譯與正式 Nuxt 建置通過。
- 尚未測量實體手機 GPU 效能。
