# 社群站位與支援操作：動畫腳本

- 開啟手機選單：杏桃奶油（斗內）、霧藍（GitHub）、薰衣草（回饋）三張操作卡依序就位。深色文字固定可讀，無跑馬燈。
- 咖啡動畫：杯碟先滑入，杯子從杯碟上抬起；咖啡液面升起、三道蒸氣錯開上升，咖啡豆隨杯子落回杯碟。點按立即開啟斗內視窗，放大的咖啡杯接續同一段動作。
- GitHub 動畫：小型儲存庫卡片展開，主星從卡片後方升起、轉向前方；兩顆小星在不同深度向外散開再淡出，主星停在卡片上。桌面指向或鍵盤聚焦可重播；手機初次展開也會播放。按下星星略微壓縮並亮起，原生連結立即開啟。
- 回饋動畫：兩張對話卡前後錯位展開，再疊合回原位，銜接回饋視窗。
- 快速操作／收回：先取消前次動畫再開始；指標移開、取消触控或失焦會收回所有動態圖層；關閉或卸載還原 GSAP context。減少動態偏好與偏好中途切換時直接恢復完整靜態物件。觸控滑動不阻擋、不等待動畫才導航。
- 手冊選擇「在本站地圖查看」：收起手冊與篩選，切換對應飾品，移到精確站位；位置標記打開來源卡，卡片輕微上移淡入。
- 純點篩選變更／移動地圖：只呈現選取飾品、可見範圍內、有座標且明確回報純點的站位；街道尺度顯示所在 L17 格的綠色虛線框。關閉社群圖層一併收回標記與虛線。
- 社群站位不改動網格種類數量與紅黃綠。虛線格代表格內有玩家站位，不代表整格已實測。卡片保留原始名稱、日期、作者與來源。
