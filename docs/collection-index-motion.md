# 收藏目錄：快速圖示索引

- 開啟：保留雙層紙張抽出，縮小標題區；手機以五欄圖示網格呈現分類，圓環顯示真實收藏百分比，種類名稱保留兩行。
- 頁籤：一般／特殊直接切換網格，切換後回到網格頂端。新頁面小幅入場；快速切換先清理舊動作，顯示最後一次選擇。
- 點選：按鈕輕微按壓，目錄沿原路收回，再定位到對應分類；保留既有懶載入後的定位修正。
- 關閉／中斷：反向播放開啟時間軸；切換動畫停止，恢復捲動與鍵盤焦點。減少動態時直接呈現結果。

不以長清單替代網格，不在圓環內堆疊數字；完整分類名與數量由可存取標籤及 title 提供。小螢幕仍保留至少 44px 觸控範圍；高度不足時允許目錄內捲動。

## 驗證

- 393×852：一般 43 類及特殊 58 類各頁皆不需要捲動；320×740 的一般 43 類可一次看完，按鈕約 57×56px。
- 1440×900：桌面八欄，特殊 58 類可一次看完；實際 Chrome 確認網格外觀及頁籤切換。
- 實際收藏一隻廚師帽：餐廳 1/16、6%，SVG 進度弧線同步為 6%；測試收藏已取消。
- 分類點選定位、快速切換、Escape 關閉與減少動態模式通過；關閉後 body 捲動鎖定解除。
- 型別檢查、正式編譯與修改格式檢查通過。
